# Profilbilder

Ett bilde per medlem, navngitt etter personen: `marius.jpg`, `erfan.jpg` …

Koble bildet til riktig person ved å sette `photo` i
[`src/data/team.ts`](../../src/data/team.ts). Mangler bildet, viser kortet
«Bilde kommer» — det er håndtert, ikke en feil.

Stående format (4:5) passer best, minst 800 px bredt.
